## Overview

이 프로젝트는 단순한 포트폴리오 페이지가 아니라,  
직접 만들어가는 개인 브랜딩용 Resume 웹사이트를 목표로 합니다.

현재는 기본 프로젝트 세팅을 마친 상태이며, 첫 화면은 `Hello`만 출력되도록 정리되어 있습니다.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint

## Getting Started

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 으로 접속하면 됩니다.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Goal

- 깔끔하고 읽기 쉬운 이력서 UI 만들기
- 나를 잘 보여줄 수 있는 섹션 구조 설계하기
- Codex만으로 어디까지 만들 수 있는지 기록 남기기
